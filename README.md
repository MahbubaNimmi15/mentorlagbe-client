
# MentorLagbe — Smart Tuition & Mentorship Platform

MentorLagbe is a full-stack tuition management platform connecting students, tutors, and administrators.

## Live Website
https://mentorlagbe-client-mp4j.vercel.app

## GitHub Repositories
- Client: https://github.com/MahbubaNimmi15/mentorlagbe-client
- Server: https://github.com/MahbubaNimmi15/mentorlagbe-server

## Technologies
- Next.js
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- ImgBB

## Features
- Student, Tutor, and Admin role-based dashboards
- Tuition posting and management
- Admin tuition approval and rejection
- Student tuition applications
- Tutor applicant management
- Profile editing and image uploads
- Search and filter tuition listings

## Running Locally

### Client
npm install
npm run dev

### Server
npm install
npm run dev

Configure the required environment variables before running.

## Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
